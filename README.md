# Librix API

A modern RESTful book borrowing and library management API built with Go.

## API testing (Bruno)

A ready-to-use [Bruno](https://www.usebruno.com/) collection covering every
endpoint lives in [`bruno/librix-api`](bruno/librix-api). Start the API with
`make run`, open that folder in Bruno, select the `local` environment, and send
the requests. See [`bruno/librix-api/README.md`](bruno/librix-api/README.md) for
the endpoint table and suggested testing order.
